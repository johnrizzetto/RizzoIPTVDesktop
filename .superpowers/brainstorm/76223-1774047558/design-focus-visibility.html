Focus Changes Summary

  • Border: 1.5dp @ 15% opacity → 2dp solid cyan (full opacity)
  • Glow: None → 20dp cyan outer glow (box-shadow)
  • Left accent bar: New — 4dp solid cyan on channel rows
  • Background: Subtle tint → horizontal gradient (cyan→transparent)
  • Scale: 1.02x → 1.03x on rows, 1.06x → 1.08x on cards
  • Text: SemiBold → Bold + pure white on focused item
  • Dimming: New — unfocused siblings fade to 50-70% opacity so focused item pops
